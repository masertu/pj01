คำตอบที่ถูกต้อง

สาเหตุ: CPU ทำงานหนักเกินไปร่วมกับการระบายความร้อนที่ไม่ดี

คอมพิวเตอร์ช้าลงเพราะมีโปรแกรม Background ที่กิน CPU สูงถึง 98% ทำให้อุณหภูมิ CPU ขึ้นสูง จนระบบ Thermal Throttling เข้ามาลดความเร็ว CPU โดยอัตโนมัติเพื่อป้องกันความเสียหาย ประกอบกับ RAM เต็มจาก Tab เปิดค้างจำนวนมาก ทำให้ระบบต้องใช้ Virtual Memory ซึ่งช้ากว่า RAM จริงมาก

📚 สิ่งที่เรียนรู้จากคดีนี้

🧠

CPU (Central Processing Unit)

หน่วยประมวลผลกลาง เมื่อ CPU ทำงานหนักเกิน 90% ระบบจะช้าลงอย่างเห็นได้ชัด

💾

RAM (Random Access Memory)

หน่วยความจำชั่วคราว เมื่อ RAM เต็ม ระบบจะสลับไปใช้ Virtual Memory บน HDD ซึ่งช้ากว่ามาก

🌡️

Thermal Throttling

เมื่อ CPU ร้อนเกินไป ระบบจะลดความเร็วอัตโนมัติเพื่อป้องกันความเสียหาย

⚡

Cache Memory

หน่วยความจำเร็วพิเศษใน CPU ช่วยลดเวลาดึงข้อมูลจาก RAM
